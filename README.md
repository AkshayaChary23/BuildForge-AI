# BuildForge AI

BuildForge AI is an intelligent platform compiler that converts natural language product requirements into structured executable application configurations.

## Features

- Intent Extraction
- System Design Layer
- UI Schema Generation
- API Schema Generation
- Database Schema Generation
- Role Based Access Control
- Validation Engine
- Auto Repair Engine
- Runtime Simulation
- Evaluation Metrics

## Tech Stack

- Python
- Streamlit
- Pydantic
- Pandas

## Example Prompt

Build a CRM with login, contacts, dashboard, premium plan with payments, and admin analytics.
